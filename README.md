# desktools

基于 Tauri 2 + Vue 3 + TypeScript 的桌面工具箱（Windows / macOS）。

## 功能

- **侧边栏菜单**：「剪贴板历史」「文件中转站」「日志」「软件更新」「系统设置」五个页面单页切换，侧边栏常显 MQTT 连接状态。
- **剪贴板跨设备同步（MQTT）**：在「系统设置」中配置 MQTT 连接（服务器 / 端口 / 用户名 / 密码 / TLS）与 Group 号，程序启动即自动连接并订阅 `texthub/<group号>`；本机每次复制文本自动发布到该 topic，收到其他设备的内容自动写入剪贴板（消息携带本机设备 ID，自动忽略自身消息避免回环）。配置持久化保存（密码与 MinIO 凭据同样以机器绑定加密存储，配置文件不落明文），连接状态实时显示。
- **剪贴板历史**：自动保存最近 200 条复制记录（含远端同步内容，标记来源），支持点击条目重新复制、单条删除、一键清空（弹窗确认）；相同内容去重并置顶，历史持久化保存。
- **内容识别与快捷操作**：历史中的内容自动识别类型（链接 / 邮箱 / 电话 / 颜色值 / JSON / 文件路径 / Base64 / 数学算式 / Markdown）并显示类型徽标，按类型提供一键快捷操作：打开链接、色块预览与复制 HEX·RGB、JSON 格式化预览与压缩复制、在访达 / 资源管理器中定位、写邮件、拨打、Base64 解码预览、算式直接算出结果、Markdown 渲染预览。识别与操作全部在本机完成、不联网，所有动作均由点击手动触发。
- **文件中转站（MinIO）**：在「系统设置」中配置 MinIO（S3 兼容）服务器地址、存储桶（默认 `hub`，不存在时自动创建）与 Access Key / Secret Key 后，可跨设备上传、下载、删除文件（同名文件覆盖；删除前弹窗确认）。支持把文件直接拖拽到页面释放上传，以及「粘贴图片」一键上传剪贴板里的截图 / 图片（自动转 PNG，也可 Ctrl+V）。大文件自动分片、流式传输并实时显示进度；下载中断自动清理半成品。凭据以机器绑定加密存储在本机（配置文件里是 `enc:v1:` 密文，更换电脑或重装系统后需重新填写）。
- **运行日志**：记录 MQTT 连接/订阅/断线重连、**收发消息内容**、历史写入、剪贴板读写等关键事件（INFO / WARN / ERROR），日志页支持级别筛选、刷新、清空（弹窗确认）；日志持久化到文件（内存保留 1000 条，文件超 1MB 自动轮转）。
- **锁屏联动**（可选，收 / 发两个独立开关）：在「系统设置 → 锁屏同步」中开启。**广播我的锁屏**—本机锁定 / 解锁经 `locksync/<group号>` 通知同组设备；**跟随其他设备锁屏**—收到远端锁屏事件时本机跟随锁定（解锁事件仅唤醒屏幕到锁屏界面，需输入密码，不会绕过密码）。跟随侧内置**活跃守卫**：本机最近 N 秒（默认 300，可调，0 = 总是跟随）内有键鼠操作则跳过锁定——正在使用的设备（如工作机）不会被其他设备的联动误锁。锁屏状态在本机检测（macOS 会话锁屏标志 / Windows 输入桌面）；应用远端事件后短暂抑制本机回传，避免多台设备互相触发循环。需先配置 MQTT 连接。
- **按键同步**（可选）：在「系统设置 → 按键同步」中开启后，本机任意窗口下按下配置的**源组合**（如 `Ctrl+↓`）会经 `keysync/<group号>` 广播「源组合 + 目标组合 + 目标平台」，同组设备**没有同源规则时按发送端映射直接注入**（单向配置即生效）；接收端若也配置了同源启用规则，则以本机规则为准——每台设备可映射到不同的目标按键。规则支持按键录制 / 手动输入与单条启用禁用（禁用的规则允许保留未填写的组合），改动 5 秒后自动保存。主键支持字母 / 数字 / F1~F12 / 方向键 / PageUp / PageDown / Home / End / Enter（按物理键位对应，与输入法布局无关），目标组合支持单键（无修饰键）。Windows 使用全局键盘钩子，后台失焦同样生效；macOS 监听按键需在 系统设置 → 隐私与安全性 → **输入监控** 勾选 desktools（缺权限时总开关自动回退关闭并记录提示），注入按键需在 **辅助功能** 中勾选 desktools（首次收到远端按键且未授权时会主动弹出系统授权面板；未勾选时注入会尽力尝试并记录一次警告，目标应用无反应请检查此项；授权后建议重启应用，开发构建重新安装后如授权失效请移除旧条目重新添加）。注意 mac F 键（F9 等）默认被系统媒体键接管，直接按不会产生 F9——用组合框下方的「F…」下拉选择（F1~F12）或直接键入 `f9`，也可按住 Fn 再按；注入时同理：目标为**无修饰键的 F7~F12** 时，若系统未勾选「将 F1、F2 等键用作标准功能键」，会按物理键语义注入媒体键（F7 上一首 / F8 播放暂停 / F9 下一首 / F10 静音 / F11 音量减 / F12 音量加），从而控制 QQ 音乐、Music 等只响应媒体键的应用；需要普通 F 键时请在系统设置中勾选该选项，或给目标组合加修饰键（如 `Cmd+F9`）。macOS 系统级快捷键（调度中心 Ctrl+↑↓、切换空间 Ctrl+←→、输入法 Ctrl+Space 等）也会优先拦截按键，录制这类组合请先点组合框下的修饰键按钮（Ctrl / Option / Shift / Cmd）再点 ↑↓←→ 等主键（也可按住修饰键点主键，或直接键入键名如 `ctrl+down`），也可临时停用对应系统快捷键。开关默认关闭；消息带 300ms 去重（长按不重复触发）、改动规则不打断正在进行的剪贴板同步。
- **桌面右键菜单**：桌面空白处右键 →「剪贴板历史」/「文件中转站」，直接弹出对应的独立小窗口。Windows 为注册表静态菜单项（Windows 11 需点「显示更多选项」），macOS 为 Finder「快速操作 / 服务」；均可在「系统设置 → 系统集成」中开关。托盘右键菜单同样可弹出这两个窗口。
- **自动更新**：内置 minisign 公钥验签，启动时自动检查 GitHub Releases 更新（也支持手动检测），下载安装后自动重启。版本号由 git 提交自动生成（`1.0.<提交数>`）。
- **开机自动启动**：默认随系统登录自启动（带 `--hidden` 参数，仅驻留托盘不弹窗），可在应用内关闭/开启；开关状态持久化在 `config.json`（`autoStart`），关闭后不会被下次启动重新打开。开发构建（`pnpm tauri dev`）不管理系统自启，避免自启条目指向 `target/debug` 二进制。
- **最小化到托盘**：关闭窗口不退出程序，最小化到系统托盘；托盘菜单可「剪贴板历史」「显示主窗口」或「退出」。

## 开发

```bash
pnpm install
pnpm tauri dev
```

> 同步配置保存在 `~/Library/Application Support/com.hyy.desktools/config.json`，剪贴板历史保存在同目录的 `history.json`（Windows 为 `%APPDATA%\com.hyy.desktools\`）。

## 构建

```bash
pnpm tauri build
```

产物位于 `src-tauri/target/release/bundle/`（macOS：`.dmg`；Windows：`.exe` NSIS / `.msi`）。

## CI / 发布

- `.github/workflows/ci.yml`：`develop` / `release/**` / `hotfix/**` / `feature/**` 分支及 PR 推送时构建验证（macOS + Windows）。
- `.github/workflows/release.yml`：**每次推送到 `main`** 自动构建 macOS + Windows 并发布到 GitHub Releases，无需手动打 tag：
  - 版本号：`1.0.<git 提交数>+<短SHA>`（写入应用配置）
  - Release tag：`v1.0.<提交数>-<短SHA>`

> **macOS 安装提示**：产物为 universal 包（Apple Silicon / Intel 通用）与 Windows x64 安装包。
> macOS 产物已做 ad-hoc 签名但未经过 Apple 公证（无开发者账号），首次打开若提示"无法验证开发者 / 未公证"：
>
> ```bash
> xattr -cr /Applications/desktools.app   # 清除隔离属性后正常打开
> ```
>
> 或在 Finder 中右键 → 打开（macOS 15+ 需在「系统设置 → 隐私与安全性」中点"仍要打开"）。
> 若提示"文件已损坏"，说明签名无效，请在仓库提 Issue 反馈（CI 已内置签名校验，正常不会出现）。
